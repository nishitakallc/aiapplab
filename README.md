## 作るアプリについて

この資料の手順で完成するのは、**ブラウザで開くだけで動く HTML 1ファイル**のおこづかい帳です。

- 収入・支出の記録入力
- 残高の自動計算
- 通帳をイメージした使いやすいデザイン
- Excel でのデータ書き出し（日付／内容／区分／収入／支出／残高）

**アプリ本体のファイルは、このリポジトリには置いていません。** ご自身の手で Claude に作らせるところまでが、この資料の内容だからです。完成したファイルは、あなただけのものになります。
